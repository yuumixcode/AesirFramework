## 目标裁决（决定"要不要做"）

- [2026-11-19 02:41:17] **无 Odin UI Toolkit 复刻的判据（推翻 11-18 把 Binder+SDG UIToolkit 窗口当成果的口径）**：**只有影响代码运行或配置的类型才需要无 Odin 的 UI Toolkit 显示**。Binder 与 Script Doc Generator 既不影响运行也不影响配置 → 移除它们的 UI Toolkit 版本窗口（AesirBinderWindowUIElements / ScriptDocGeneratorWindowUIElements 已走废纸篓），只保留原 Odin 工具；SceneAssetWrapper 运行时用于配置、可能影响加载 → 必须有零 Odin 的 UI Toolkit 绘制（CreatePropertyGUI，IMGUI OnGUI 兜底）+ Odin Processor 在关闭样式时注入 DrawWithUnityAttribute 让路。Why: 把"无 Odin"当普遍目标会让纯编辑器工具背上无意义改造。How to apply: 样式开关从 EditorPrefs + Tools 菜单（旧形态作废）改为 Editor 专属 AesirInspectorStyleSettingsSO + `Preferences → Aesir` 设置页；"两个 SO"= Editor 只读样式 SO + 随构建分发的运行时 SceneModuleConfigSO。RuntimeInitializeLoadType 示例配置窗口不再有独立菜单项，由 Getting Started 卡片右侧按钮打开。
- [2026-11-18 03:23:28] **复刻三条实测结论**：①Unity 2022.3 **支持开放泛型 `[CustomPropertyDrawer(typeof(ObservableValue<>))]`**（`ScriptAttributeUtility.GetDrawerTypeForType(type,false)` 实测 int/string/Vector3 全解析到同一 drawer，社区旧帖"原生不支持泛型 drawer"已过时）。②让装有 Odin 时也能切 UI Toolkit：`AesirInspectorStyleSettings.UseOdin`（RAA.Editor/Common，EditorPrefs key `Aesir.Editor.UseOdinInspectorStyle`，菜单 Tools/Aesir/Use Odin Inspector Style，默认 true）。**关键**：仅让 Odin AttributeProcessor `return` 不够——Odin 仍接管字段绘制；必须在 `ProcessSelfAttributes` 注入 `new DrawWithUnityAttribute()` 强制让路。窗口侧 4 个兜底窗口 `Open()` 判据加 `UseOdin && OdinWindowOpener != null`。③RAA.Editor 的 internal 类要被 RAM 用，需在 `Editor/Common/AssemblyInfo.cs` 加 `InternalsVisibleTo("Runestone.AesirModules.Editor")`（程序集引用不传递，RAM.Editor.Odin 需再补引用）。技巧：`GetDrawerTypeForType` 是 2 参数非公开方法；`CustomPropertyDrawer` 目标类型存私有字段 `m_Type`。

## 验证方法与坑位

- [2026-11-18 03:56:05 / 04:01:23 / 04:02:52] 无 Odin 验证脚本可靠做法：①移除 ODIN_INSPECTOR 宏后**必须同时把 `Assets/Plugins/Sirenix` 连同 .meta 用 trash 隐藏**——只移除宏而插件仍在，Odin 编辑器代码 batchmode 启动时会把宏写回（实测宏变回 `ODIN_INSPECTOR;AESIR_ARCHITECTURE;...`），是无效验证。②不要 `mv Sirenix → Sirenix.disabled` 再 mv 回来——Unity batchmode 会在原路径重建空壳（0 DLL），导致 trap 恢复时目标已存在失败、完整 Odin 被困嵌套 `Sirenix/Sirenix.disabled/`。正确：cp -R 备份到 /tmp + trash 隐藏 + trap 从备份恢复。③移除宏用 `git checkout -- ProjectSettings/ProjectSettings.asset` 恢复，不要 sed（会重复追加宏）。④恢复后核对 14M/11 DLL 与 Standalone 宏行（579 行是宏，167 行 `Standalone: 0` 是播放器配置非宏）。**权威结果**：有/无 Odin 编译均 0 CS 错误，EditMode 865/862/0/3、PlayMode 36/36。
- [2026-11-19 02:41:23] 补充无 Odin 验证新坑（同上，重申）：只改宏不隐藏插件是无效验证；本轮权威结果有/无 Odin 编译 0 错误、EditMode 865/862/0/3、PlayMode 36/36。

## Odin 面板/绘制坑位（本仓反复踩，日常写 Odin 代码时查）

- [2026-11-08 12:21:45] ①`InspectorProperty.Draw` 对只读属性/只读集合子项推 `PushGUIEnabled(false)`，同链 InfoBox/文本全变灰 → 只读展示成员一律加 **`[EnableGUI]`**；文案用**属性**（静态字段初始化器里调 AssetDatabase 抛 `GUIDToAssetPath_Internal is not allowed`）。②多个 `ShowIf` 是 **OR** 语义，AND 要写一个复合条件属性。③`[Title]` Subtitle 自带 alpha×0.7，深色主题像 Disabled → 手绘标题。④`SirenixGUIStyles.MiniButton` 背景不随 rect 高度拉伸（恒 ~18px）→ 变大按钮换 `SirenixGUIStyles.Button`。⑤类级 `DetailedInfoBox` 只能一个（两个抛 `state already exists`）。⑥InfoBox 的 `$value` 在 bool 字段上指该 bool 值；静态文案用 `"$" + nameof(常量)`（resolved-string 参数必须编译期常量，`static readonly` 报 CS0182）。⑦`TitleGroup` 把成员收进组节点（结构探针须递归）；`State.Visible` 在 `PropertyTree.Create` 后即有值。⑧窗口 `PropertyTree` 必须 `OnDisable` 里 `Dispose()`；**绘制回调禁止解析资产库单例**（触发全项目重扫并报 `GUIStateObj is deleted`），单例收敛到 `OnEnable` 并按域缓存。⑨AttributeProcessor 用 `internal sealed` + 与目标类同文件，成员匹配靠 `nameof`。⑩窗口交互裁决：概览卡整卡不可点、只有底部按钮可点；示例卡整卡 = PingSample + Toast、右侧按钮 = 打开场景。
