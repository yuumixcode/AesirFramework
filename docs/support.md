# 获取帮助与贡献

## 获取帮助 {#help}

- **问题反馈与功能建议**:[GitHub Issues](https://github.com/yuumixcode/AesirFramework/issues) —— 提问时附 Unity / 团结引擎版本、包版本与最小复现步骤
- **源码仓库**:[yuumixcode/AesirFramework](https://github.com/yuumixcode/AesirFramework)(MIT)· 国内下载镜像 [CNB](https://cnb.cool/runestone-game/AesirFramework)(Issue / PR 请走 GitHub)
- **作者**:yuumixcode([主页](https://github.com/yuumixcode))

## 提问前自查 {#self-check}

1. 版本是否为最新?(`Tools → Aesir → Check for Updates` 或 Package Manager 检查)
2. 是否踩中高频陷阱?框架异常消息(fail-fast)大多已含修复指引,详见[常见问题 FAQ](../faq.md)
3. Odin / Addressables / Input System 相关问题请注明是否安装(可选项影响代码路径)

## 如何贡献 {#contributing}

欢迎任何形式的贡献 —— Bug 报告、功能建议、文档改进、代码提交:

- 阅读主仓库 [CONTRIBUTING.md](https://github.com/yuumixcode/AesirFramework/blob/main/CONTRIBUTING.md) 了解提交流程
- 遵循 [CODE_OF_CONDUCT.md](https://github.com/yuumixcode/AesirFramework/blob/main/CODE_OF_CONDUCT.md)
- 推荐从 `main` 拉分支;提交信息遵循 Conventional Commits
- 文档问题(含本站点)可直接对主仓 [docs/ 目录](https://github.com/yuumixcode/AesirFramework/tree/main/docs) 提 PR(站点与主仓同仓;页面源文件路径与 URL 路径一致)
- 贡献示例场景、迁移经验或对某个模式的使用心得,也可以开 Issue 讨论后沉淀进文档

## 如何支持开发 {#support-development}

AesirFramework 采用 MIT 协议,**永久免费开源**,两个包(`Aesir Architecture` / `Aesir Modules`)都不设任何收费墙。它是独立开发维护的个人项目,如果你用得上,以下都是实实在在的支持:

- **用起来并反馈**:在真实项目中采用,把踩到的坑、边界情况与需求写进 [Issues](https://github.com/yuumixcode/AesirFramework/issues) —— 对独立开发者来说,高质量反馈比什么都值钱
- **传播**:给仓库点个 Star、向团队与社区推荐、写教程或案例文章引用本项目
- **参与共建**:提交 PR、补文档、报 Bug(见上方「如何贡献」)
- **关注同类作品**:作者的其他开源项目如 [AesirInspector](https://github.com/yuumixcode/AesirInspector),使用与反馈同样是对开发的支持

!!! tip "致谢与参考来源"

    本项目从哪些开源项目与商业插件中提取、参考了哪些设计,集中收录在[推荐项目与参考致谢](product/acknowledgments.md) —— 站在肩膀上的部分,都写在那里。
