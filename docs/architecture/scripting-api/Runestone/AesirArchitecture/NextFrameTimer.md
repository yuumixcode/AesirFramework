## 声明


下一帧执行一次的计时器：跳过时间累减，按结算周期号判定。对应工厂 NextFrame。

**备注**

语义是"此后第一次结算"，不是"当前帧剩下的某一次结算"：创建发生在一次结算之后（如 Update、 协程、另一个计时器回调）时落在下一帧；创建发生在当帧结算之前（如 AfterAssembliesLoaded）时落在当帧。

"下一帧"按结算周期计数，与 Time.timeScale 无关，因此不接受 unscaled 参数。
