# `AesirEventMonitorWindow`

!!! note ""

    - **种类:** `class`
    - **命名空间:** `Runestone.AesirModules.Editor`
    - **程序集:** `Runestone.AesirModules.Editor`

**继承链:** `System.Object` → `UnityEngine.Object` → `UnityEngine.ScriptableObject` → `UnityEditor.EditorWindow` → `AesirEventMonitorWindow`

## 声明

``` csharp
public class AesirEventMonitorWindow : UnityEditor.EditorWindow
```

事件监视窗口（UI Toolkit 版）：以只读方式展示"哪些事件当前有哪些订阅者"。
数据全部来自公开门面 AesirEventDiagnostics，本窗口无任何内部注册表访问—— 未安装 Odin 时本窗口功能完整；装有 Odin 且开启 Aesir Odin 样式时菜单路由到 Odin 版窗口。
